# RecipeHub

Frontend-only Flutter recipe discovery app for a UID laboratory project.

## Run
1. Install Flutter SDK.
2. Extract this project.
3. Open a terminal in the `recipehub` folder.
4. Run `flutter pub get`.
5. Run `flutter run`.

## Features
- Home, Explore, Favorites, Categories and Profile tabs
- Recipe details with ingredients checklist and cooking steps
- Search and category filtering
- Add recipe form with validation
- Favorites using Provider
- Light/dark theme
- Public TheMealDB API integration (tap "Discover online recipes" on Home)
- In-memory data only; no backend or database

## Note
Internet access is needed for network food images and online recipe fetching. Sample recipes are available locally.
